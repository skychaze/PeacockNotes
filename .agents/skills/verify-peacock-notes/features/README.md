# Feature map

Index of user-facing features and how to prove each one by driving the app.
A proof that drives one convenient entry point is incomplete when this map
lists others. Start every drive on the Folders screen in English (tap `EN`).

- `folders.md`: create, rename, delete, sort, reorder folders.
- `notes-list.md`: browse, search, sort, reorder, delete notes in a folder.
- `note-editor.md`: write text, record/import audio, attach files, share.
- `backup.md`: export archive, selective/additive/replacement import, automatic backup.
- `storage-share.md`: storage breakdown, receiving shared files.
