# Peacock Notes 1.1.11

## Release

- Version: 1.1.11
- Version code: 23
- Android package: com.roy.peacocknotes

## Changes

- APK updates download through Android Download Manager and continue while the app is in the background.
- Show download progress and wait states when Android pauses a download for Wi-Fi or network availability.

## Compatibility

- Existing notes, folders, and attachments remain compatible.
- This release adds native Android download handling and uses runtime 1.1.11. Install this binary before receiving JavaScript updates for this runtime.
- The package name and signing key are unchanged, so Android can update an existing installation in place.
