# Peacock Notes 1.1.12

## Release

- Version: 1.1.12
- Version code: 24
- Android package: com.roy.peacocknotes

## Changes

- Select or deselect all notes in the backup import preview, with English and Bengali labels.
- Reuse the verified backup archive during import and restore only selected notes and attachments with their required folders.
- Estimate import storage from selected content and clean up abandoned import sessions.
- Use one silent progress notification for backup work and clear it when work finishes or interrupted work recovers.
- Open the Updates screen by tapping the version label on the folders screen.

## Compatibility

- Existing notes, folders, and attachments remain compatible.
- This release updates native Android backup handling and uses runtime 1.1.12. Install this binary before receiving JavaScript updates for this runtime.
- The package name and signing key are unchanged, so Android can update an existing installation in place.
