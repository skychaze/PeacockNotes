# Peacock Notes 1.1.13

## Release

- Version: 1.1.13
- Version code: 25
- Android package: com.roy.peacocknotes

## Changes

- Resume large Google Drive backups after a lost connection or app process restart.
- Keep the staged archive and upload session when a temporary network outage interrupts export.
- Show retry progress while the app waits for the connection to return.

## Compatibility

- Existing notes, folders, attachments, and backups remain compatible.
- This release updates native Android backup handling and uses runtime 1.1.13. Install this binary before receiving JavaScript updates for this runtime.
- The package name and signing key are unchanged, so Android can update an existing installation in place.
